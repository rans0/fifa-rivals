Rules & Calculations

How every rating and stat on this site is computed. All numbers are recomputed from data.json in date order — deterministic, same result every time.

ELO rating

Every player starts at 1200. After each match, both ratings are updated using the standard Elo system with K = 32:

EA = 1 / (1 + 10(RB − RA) / 400)   ← expected score of A
ΔA = round( 32 × (SA − EA) )   ← rating change of A
R'A = RA + ΔA  ·  R'B = RB − ΔA

The actual score S is 1 for a win, 0.5 for a draw, 0 for a loss. The change is rounded to a whole number each match and is always zero-sum: what the winner gains, the loser loses.

Worked example — deltas from the lower-rated player's view

Rating gapExpected W WinDrawLoss
Equal (1200 vs 1200)50%+16±0−16
−100 (1200 vs 1300)36%+20+4−12
−200 (1200 vs 1400)24%+24+8−8
−400 (1200 vs 1600)9%+29+13−3
  • Upsets pay more. The bigger the rating gap, the more the underdog gains by winning — and the more the favorite loses. A favorite beating an underdog 400 below gains only +8 (mirror of −400 Loss).
  • Drawing against a higher-rated player earns ELO (+4 / +8 / +13 above), because the draw (0.5) beat the expectation.
  • Goals do NOT affect ELO. Only the result W/D/L matters — a 7–0 win moves the rating exactly as much as a 1–0 win. Goals only feed GF/GA, +/−, and the Records cards.
  • Match order: matches are processed in date order (same date → order in data.json), each match using the ratings left by the previous one.

Crowns & the sash

TermDefinition
Match DayOne date that has matches. Numbered from the oldest = 1.
👑 Crown HistoryWho ended each match day ranked #1 by ELO. Consecutive days on top merge into one reign.
⛰️ King of the HillNot ELO-based. The winner of the first non-drawn match becomes the inaugural holder. After that, only matches featuring the holder count: win or draw = successful defense, loss = the sash passes to the challenger. Matches without the holder change nothing.
